# SmallRNA Reference Database

Repository: https://github.com/wwdff/SmallRNA-Reference-Database

This initial repository package provides reference descriptions, category summaries and source notices. Prepared on 2026-11-05. Public upload awaits owner approval.

## Reference scope

Human GRCh38 contains 32,294 unique sequences and 57,778 source records in the local candidate. It reuses RNAcentral Release 20 and NCBI 45S rRNA NR_145819.1. Supplemental GtRNAdb mature tRNA+CCA is excluded from this candidate. RNAcentral includes miRNA and pre-miRNA; piRNA was excluded by the inherited construction rules.

Mouse GRCm39 contains 8,477 unique sequences and 12,472 source records in the local complete candidate. Sources are Ensembl116 ncRNA, GtRNAdb mature tRNA, NCBI 45S NR_046233.2, two local small RNA FASTAs and miRBase21. Full mouse FASTA has not been publicly released. Most mouse source records remain PENDING for provenance or redistribution clearance.

## Included files

Human and Mouse category summaries describe the local candidate scope. They are not counts of publicly available sequences. Each species checksum file verifies only README.md and category_summary.tsv shipped in this initial package. SOURCE_LIST.xlsx documents sources and status. LICENSE_NOTICES.md records source-specific terms.

No FASTA or full metadata is included in this initial package. Citation and license details remain source-specific. Project authors and DOI have not been supplied. Cite the underlying databases using the species README and source list.
